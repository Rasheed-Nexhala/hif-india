# HIF India Website

React + TypeScript + Vite site for Highland Islamic Forum (HIF India), deployed on Firebase Hosting.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run lint` — Oxlint
- `npm run preview` — preview production build
